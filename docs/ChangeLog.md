- Shared `GraphException.isDuplicateValue` replaces the private check in the Employees service.
- Issues module (branch feature/tasks): report an issue (anyone), list with status filter, "Assigned to me" and search, Details dialog with actions. Team Lead / Management / Admin assign; the assignee investigates, sets Waiting or Resolved (remarks required); the reporter or a lead confirms and closes or reopens (reason required); a lead can close without fixing (reason required). Closed is final. IssueCode `ISS-<year>-<5 digits>` with duplicate retry. `ResolutionRemarks` holds the latest note. `AppConfig.issuesListId` added; new sidebar item "Issues". Time Tracker hidden (`showTimeTracker: false`). Tests: `test/issue_service_test.dart`. Not yet compiled or run.
- Daily Reports (branch feature/tasks): write a daily report (completed, planned, pending, problems, tomorrow's plan, total hours), save as draft or submit, edit while Draft or Returned, Team Lead / Management / Admin accept (Reviewed) or send back (Returned, reason required). One report per person per day, enforced by the unique ReportCode `DR-<EmployeeID>-<yyyyMMdd>`. Employees see only their own reports; leads can see everyone's. New sidebar item "Daily Reports". `AppConfig.dailyReportsListId` added. `TotalHours` is typed by the person (the Time Tracker is hidden, so it is not calculated from time logs). Tests: `test/daily_report_service_test.dart`. Not yet compiled or run.
- Task dates and hours used (branch feature/tasks): the task Details dialog now shows a Timeline (Accepted, Work started, Submitted for review = job ended, Approved) in Malaysia time, the hours used in office hours (Mon-Fri 09:00-18:00, On Hold and review waiting taken out) and the variance against the original estimate. New IT_Tasks columns `AcceptedAtUTC`, `SubmittedAtUTC`, `HoldStartedAtUTC`, `HeldMinutes` (run `scripts\Create-ItdmpLists.ps1 -Lists IT_Tasks`). New `OfficeHours`, `TaskHours`. `AppConfig.showTimeTracker` hides the Time Tracker (page, sidebar item and top bar timer) without removing code. Tests: `test/task_hours_test.dart`. Not yet compiled or run.
- Time Tracker step 1 (branch feature/tasks): Start, Pause, Resume, End job, recovery of the running timer from SharePoint at sign-in, today's finished segments and total, running timer chip in the top bar. One IT_TimeLogs row per work segment; `ActiveTimerKey` = `ACTIVE|<EmployeeID>` (unique) while running and cleared when the segment ends; updates use ETag. New: `TimeLog`, `TimeLogRepository`, `TimeTrackingService`, `YearlyCode` (shared by TaskCodes and TimeLogCodes), `RuleViolation`. `AppConfig.timeLogsListId` added. Tests in `test/time_tracking_service_test.dart`. Not yet compiled or run. Manual correction, approval and task actual hours come in step 2.
- Tasks module step 2 (branch feature/tasks): estimate revisions (request, Team Lead approve or refuse; the original estimate never changes), documentation flow (submit, accept, send back, waive with reason), Details dialog, `TaskCapabilities` shared by the service and the screen, and a fix so changing "Documentation required" in the form resets the documentation status. New IT_Tasks columns `ProposedEstimatedHours` and `DocumentationRemarks` (run `scripts\Create-ItdmpLists.ps1 -Lists IT_Tasks`; it only adds the missing columns). `RevisedEstimatedHours` now holds only an approved revision. Tests in `test/task_step2_test.dart`. Not yet compiled or run.
